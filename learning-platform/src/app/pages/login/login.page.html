Continue with Google

To enable Google login:

  1. Go to console.cloud.google.com
  2. Create a project → APIs & Services → Credentials
  3. Create OAuth 2.0 Client ID (Web app)
  4. Add http://localhost:4200 to Authorized JavaScript origins
  5. Copy the Client ID into environment.ts → googleClientId
  6. Add GOOGLE_CLIENT_ID=your-id to backend/.env
